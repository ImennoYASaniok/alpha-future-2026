

# **ТЗ: Интерактивный прототип — "Первый кредит без страха"**

## **Контекст и цель**

Сценарий: молодой человек 18–25 лет впервые хочет взять кредитную карту или рассрочку в Альфа-Банке. Текущий путь — стена текста, непонятные условия, страх отказа и ощущение ловушки. Мы переосмысляем этот сценарий.

**Формат артефакта:** интерактивный кодовый прототип (HTML/React) — кликабельный, работает в браузере, без бэкенда.

---

## **Экраны для реализации (User Flow)**

### **Экран 1 — Точка входа**

* Заголовок: *"Хочу первую кредитную карту"*  
* Короткий текст: "Разберёмся вместе — без сложных условий"  
* Кнопка: **"Начать"**

---

### **Экран 2 — 3 простых вопроса (онбординг)**

По одному вопросу на шаге, прогресс-бар сверху.

**Шаг 1:** Сколько тебе лет? 18–20 / 21–23 / 24–25 **Шаг 2:** Есть ли доход? Работаю / Фриланс/подработки / Учусь, дохода нет **Шаг 3:** Зачем карта? Повседневные покупки / Крупная покупка / Просто хочу попробовать

---

### **Экран 3 — Честный прогноз одобрения**

На основе ответов (логика в коде, без реального API):

* Большой индикатор: **"Вероятность одобрения: высокая / средняя / низкая"**  
* 2–3 строки объяснения простым языком: *"Без официального дохода банки одобряют реже, но для первой карты с лимитом до 10 000 ₽ это реально"*  
* Кнопка: **"Посмотреть подходящие карты"**

---

### **Экран 4 — Симулятор "Что будет если"**

Ключевой экран, самый важный.

* Слайдер: **Лимит карты** (10 000 — 100 000 ₽)  
* Слайдер: **Сколько потрачу в месяц** (1 000 — 50 000 ₽)  
* Тогл: **Буду платить вовремя** / **Иногда буду задерживать**  
* Результат обновляется в реальном времени:  
  * ✅ Переплата за год: **0 ₽** (если платишь в льготный период)  
  * ⚠️ Переплата если задержу: **\+2 300 ₽**  
  * 📅 Льготный период: **60 дней**

---

### **Экран 5 — Карточка продукта**

Одна рекомендованная карта (не список из 10):

* Название карты, 1 строка — почему она подходит именно тебе  
* 3 иконки с условиями: лимит / кэшбэк / льготный период  
* Кнопка **"Оформить"** (заглушка) и ссылка **"Посмотреть другие варианты"**

---

### **Экран 6 — Подтверждение / финал**

* *"Заявка займёт 3 минуты. Решение — сразу."*  
* Чеклист что понадобится: паспорт, телефон, пара минут  
* Кнопка **"Заполнить заявку"** (заглушка)

---

## **Технические требования**

| Параметр | Значение |
| ----- | ----- |
| Стек | React или чистый HTML/CSS/JS |
| Бэкенд | Не нужен, вся логика на фронте |
| Адаптивность | Мобильный вид в приоритете (375px) |
| Анимации | Лёгкие переходы между экранами (fade/slide) |
| Цвета | Красный Альфа-Банка \#EF3124, белый, светло-серый |
| Шрифт | Inter или системный sans-serif |

---

## **Логика прогноза одобрения (псевдокод)**

если доход \= "нет" → вероятность \= "средняя"  
если возраст \= "18-20" И доход \= "нет" → вероятность \= "низкая"    
если доход \= "работаю" → вероятность \= "высокая"  
если доход \= "фриланс" → вероятность \= "средняя"

---

## **Что НЕ нужно делать**

* Не делать полное банковское приложение  
* Не подключать реальный API  
* Не верстать все продукты Альфа-Банка  
* Не делать регистрацию/авторизацию

---

## **Приоритет экранов если мало времени**

**Must have:** Экраны 2, 3, 4 (вопросы \+ прогноз \+ симулятор) — это ядро идеи. **Nice to have:** Экраны 1, 5, 6 — вход и финал.
