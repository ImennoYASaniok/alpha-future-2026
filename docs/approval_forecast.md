# Улучшение прогнозирования одобрения кредитной карты

## Текущее состояние (проблема)

Сейчас в `Screen3.jsx` логика прогноза выглядит так:

```js
if (income === 'работаю') → 'высокая'
if (income === 'фриланс') → 'средняя'
if (income === 'нет' && age === '18-20') → 'низкая'
else → 'средняя'
```

**Проблемы:**
- Только 3 исхода: высокая / средняя / низкая — без числового значения
- Цель кредита (`purpose`) вообще не влияет на прогноз
- Нет ощущения "живого" расчёта — пользователь не понимает, почему именно такой результат
- Нет дифференциации внутри категорий (например, "работаю" всегда = высокая, независимо от возраста)
- Нет рекомендованного лимита, привязанного к прогнозу

---

## Идея улучшения: Скоринговая модель с числовым баллом

### Концепция

Вместо трёх `if`-ов — **скоринговая система с баллами** (0–100), где каждый ответ добавляет или вычитает очки. Итоговый балл переводится в вероятность (%) и категорию. Это:

1. Реалистично имитирует реальный банковский скоринг
2. Даёт числовое значение — пользователь видит "73% вероятность" вместо просто "средняя"
3. Позволяет показать **что именно влияет** на результат (breakdown по факторам)
4. Легко расширяется новыми вопросами без переписывания логики

---

## Реализация: Балльная система

### Факторы и веса

| Фактор | Вариант ответа | Баллы |
|--------|---------------|-------|
| **Возраст** | 18–20 | +10 |
| | 21–23 | +20 |
| | 24–25 | +30 |
| **Доход** | Работаю по найму | +45 |
| | Фриланс/подработки | +25 |
| | Учусь, дохода нет | +5 |
| **Цель** | Повседневные покупки | +15 |
| | Просто хочу попробовать | +10 |
| | Крупная покупка | +5 |

**Итого максимум: 90 баллов**

### Перевод баллов в вероятность и категорию

```
score 70–90  → вероятность ~85–95%  → категория "высокая"
score 45–69  → вероятность ~50–75%  → категория "средняя"
score 0–44   → вероятность ~15–40%  → категория "низкая"
```

Формула для плавного перевода:
```js
const probability = Math.round((score / 90) * 100)
// Нормализуем в диапазон 15–95% (банки никогда не дают 0% и 100%)
const displayProbability = Math.round(15 + (score / 90) * 80)
```

### Рекомендованный лимит на основе скора

```js
const getRecommendedLimit = (score) => {
  if (score >= 70) return 50000   // высокая вероятность
  if (score >= 45) return 20000   // средняя
  return 10000                    // низкая
}
```

## Что показывать пользователю на Screen3

### Вместо просто "высокая/средняя/низкая":

```
┌─────────────────────────────────────┐
│  Вероятность одобрения              │
│                                     │
│         73%                         │
│  ████████████░░░░  средняя          │
│                                     │
│  Рекомендованный лимит: до 20 000 ₽ │
└─────────────────────────────────────┘
```

### Breakdown — "Что повлияло на результат":

```
✅ Возраст 21–23: +20 баллов
✅ Фриланс/подработки: +25 баллов
⚠️ Цель — крупная покупка: +5 баллов
   (повседневные покупки дали бы больше)
```

Это ключевой UX-момент: пользователь **понимает логику** и может изменить ответы, чтобы увидеть как меняется прогноз.

### Персонализированный совет:

```js
const getTip = (score, answers) => {
  if (answers.income === 'нет' && score < 45) {
    return 'Попробуй через 6 месяцев после первой официальной работы — шансы вырастут до высоких'
  }
  if (answers.income === 'фриланс') {
    return 'Если оформишь самозанятость — банк увидит официальный доход и лимит вырастет'
  }
  if (answers.purpose === 'крупная' && score < 60) {
    return 'Для крупной покупки лучше начать с небольшого лимита и увеличить через 3 месяца'
  }
  return null
}
```

## Дополнительные вопросы (расширение онбординга)

Если хочется сделать прогноз ещё точнее — добавить 1–2 вопроса на Screen2 без перегруза:

### Вопрос 4: Есть ли уже банковские продукты?
- Дебетовая карта есть → +10 баллов (банк видит историю)
- Нет никаких карт → +0 баллов
- Уже есть кредитная карта → +15 баллов

### Вопрос 5: Как часто пользуешься банковскими приложениями?
- Каждый день → +8 баллов (цифровая активность)
- Иногда → +4 балла
- Почти не пользуюсь → +0 баллов

**Важно:** эти вопросы — опциональные (можно пропустить), чтобы не перегружать пользователя.

## Интерактивность: "Что изменится если..."

На Screen3 добавить интерактивный блок — пользователь может **поменять один ответ** и сразу увидеть как меняется прогноз:

```
Что изменится если...
[ Я оформлю самозанятость ]  → вероятность вырастет до 82% ↑
[ Подожду до 21 года ]       → вероятность вырастет до 68% ↑
```

Это реализуется просто: пересчёт `calculateScore()` с подменой одного параметра.

## Связь прогноза с симулятором (Screen4)

Сейчас Screen4 никак не связан с ответами пользователя. Улучшение:

- **Начальный лимит слайдера** = рекомендованный лимит из прогноза (не всегда 10 000)
- **Подсказка под слайдером**: "Для твоего профиля банк скорее всего одобрит до 20 000 ₽"
- Если пользователь ставит лимит выше рекомендованного → показать предупреждение: "При таком лимите вероятность одобрения снижается"

## Что нужно изменить в коде

### Screen3.jsx — заменить `calculateProbability()` на `calculateScore()`:

```js
const calculateScore = (answers) => {
  let score = 0

  // Возраст
  if (answers.age === '18-20') score += 10
  else if (answers.age === '21-23') score += 20
  else if (answers.age === '24-25') score += 30

  // Доход
  if (answers.income === 'работаю') score += 45
  else if (answers.income === 'фриланс') score += 25
  else if (answers.income === 'нет') score += 5

  // Цель
  if (answers.purpose === 'повседневные') score += 15
  else if (answers.purpose === 'попробовать') score += 10
  else if (answers.purpose === 'крупная') score += 5

  return score
}

const getCategory = (score) => {
  if (score >= 70) return 'высокая'
  if (score >= 45) return 'средняя'
  return 'низкая'
}

const getDisplayProbability = (score) => {
  return Math.round(15 + (score / 90) * 80)
}

const getRecommendedLimit = (score) => {
  if (score >= 70) return 50000
  if (score >= 45) return 20000
  return 10000
}
```

### App.jsx — передавать `answers` в Screen4:

```jsx
// Добавить answers в пропсы Screen4
<Screen4
  onNext={nextScreen}
  onBack={prevScreen}
  answers={answers}          // ← добавить
  recommendedLimit={recommendedLimit}  // ← добавить
/>
```

## Итог: что даёт это улучшение

| Было | Стало |
|------|-------|
| 3 `if`-а, 3 исхода | Балльная система, числовой % |
| Цель не влияет | Все 3 ответа влияют на балл |
| Нет объяснения | Breakdown по факторам |
| Нет рекомендации | Рекомендованный лимит |
| Screen4 изолирован | Начальный лимит = из прогноза |
| Нет совета | Персонализированный совет |

**Время реализации:** 2–4 часа (только фронтенд, бэкенд не нужен).

**Ценность для презентации:** демонстрирует продуктовое мышление — не просто "показали вероятность", а объяснили логику, дали пользователю контроль и связали экраны между собой.
