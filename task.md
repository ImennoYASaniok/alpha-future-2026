# План решения кейса: Финансовый ассистент для молодой аудитории

## Проблема и решение

**Проблема:** Молодые пользователи (18-25 лет) уходят из банковских приложений в первый месяц из-за информационной перегрузки и отсутствия понятного онбординга.

**Решение:** Создать интерактивного финансового ассистента с геймификацией, который проводит пользователя через 5 ключевых финансовых действий без сложной регистрации.

## Что нужно сделать для решения кейса

### Backend разработка

**Задачи:**
1. Настроить структуру проекта с папками для API, моделей, сервисов
2. Создать модели данных для пользователей и прогресса онбординга
3. Разработать API эндпоинты для управления пользователями и прогрессом
4. Реализовать бизнес-логику геймификации и начисления XP
5. Настроить базу данных и миграции
6. Создать систему демо-пользователей для демонстрации

**Ключевые функции:**
- Инициализация сессии по device ID
- Отслеживание прогресса онбординга
- Система уровней и достижений
- Управление демо-пользователями

### Frontend разработка

**Задачи:**
1. Создать компоненты для 6 экранов онбординга
2. Реализовать бургер-меню для переключения демо-пользователей
3. Настроить Redux для управления состоянием
4. Подключить API сервисы для взаимодействия с бэкендом
5. Добавить адаптивный дизайн и анимации
6. Реализовать навигацию между экранами

**Экраны для разработки:**
- Выбор типа пользователя (студент/специалист/другое)
- Персонализированный welcome экран
- Создание виртуальной карты
- Первая покупка с кэшбэком
- Настройка автосбережений
- Dashboard прогресса

## Клиентский путь и Happy Path

### Текущий клиентский путь (проблемный)
1. Пользователь скачивает приложение
2. Видит сложную регистрацию с паспортными данными
3. Попадает в главный экран с множеством функций
4. Не понимает, с чего начать
5. Совершает случайные действия без понимания ценности
6. Уходит из приложения через 2-3 недели

### Happy Path (идеальный путь)
1. Пользователь заходит в приложение
2. Выбирает свой тип (студент/специалист/другое)
3. Получает персонализированное приветствие
4. Создает виртуальную карту в 1 клик
5. Совершает первую покупку с бонусом
6. Настраивает автоматические сбережения
7. Видит свой прогресс и достижения
8. Продолжает использовать приложение регулярно

## Что нужно реализовать

### Backend фичи
1. **Система пользователей без регистрации**
   - Идентификация по device ID
   - Хранение типа пользователя и прогресса
   - Демо-профили для демонстрации

2. **Онбординг и прогресс**
   - Отслеживание 5 шагов онбординга
   - Сохранение завершенных шагов
   - Расчет следующего шага для пользователя

3. **Геймификация**
   - Система уровней (Новичок → Эксперт → Мастер)
   - Начисление XP за действия
   - Достижения и бейджи

4. **Виртуальные карты**
   - Создание виртуальной карты
   - Привязка к demо-счетам
   - Информация о балансе

5. **Кэшбэк и предложения**
   - Генерация предложений кэшбэка
   - Категории товаров и услуг
   - Сроки действия предложений

6. **Автосбережения**
   - Настройка сумм и периодичности
   - Расчет накопленного
   - Интеграция с балансом

### Frontend фичи
1. **Выбор типа пользователя**
   - Интерфейс выбора из трех опций
   - Визуальная обратная при выборе

2. **Welcome экран**
   - Персонализированное приветствие
   - Описание следующего шага

3. **Виртуальная карта**
   - Визуализация карты с данными
   - Интерактивные элементы управления

4. **Первая покупка**
   - Интерфейс выбора категории
   - Расчет и отображение кэшбэка

5. **Автосбережения**
   - Интерфейс настройки сумм
   - Визуализация накоплений

6. **Dashboard прогресса**
   - Отображение уровня, XP, достижений
   - Финансовые показатели (баланс, сбережения)
   - Навигация по следующим шагам

7. **Демо-режим**
   - Меню переключения пользователей
   - Управление демо-данными

8. **Управление состоянием**
   - Redux store для пользовательских данных
   - API интеграция с бэкендом

## Бизнес-логика продукта

### Сценарий онбординга
1. Пользователь выбирает свой тип (студент/специалист/другое)
2. Получает персонализированный welcome и объяснение
3. Создает виртуальную карту за 1 минуту
4. Совершает первую покупку с бонусным кэшбэком
5. Настраивает автоматические сбережения
6. Видит свой прогресс и следующие шаги

### Механика геймификации
- Система уровней: Новичок, Эксперт, Мастер
- Начисление XP за выполнение действий
- Визуализация прогресса и достижений
- Персонализированные рекомендации

### Демо-режим для MVP
- Бургер-меню с выбором тестовых пользователей
- User1 (баланс: 5000₽)
- User2 (баланс: 45000₽)
- User3 (баланс: 25000₽)
