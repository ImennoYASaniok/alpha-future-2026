# Alpha Future 2026

Прототип для кейса **"Банковское приложение будущего"**.

Интерактивный прототип — «Первый кредит без страха». Помогает молодым людям 18–25 лет разобраться в кредитных картах без страха и сложных условий.

## Стек

- **Frontend**: React 18 + Vite
- **Хранение**: localStorage (все данные на клиенте)
- **Деплой**: GitHub Pages (через GitHub Actions)

## Запуск локально

```bash
cd frontend
npm install
npm run dev
```

Открыть `http://localhost:5173` в браузере.

## Сборка

```bash
cd frontend
npm run build
```

Готовая сборка в папке `frontend/dist/`.

## Деплой

При пуше в ветку `main` GitHub Actions автоматически собирает проект и деплоит на GitHub Pages.

## Структура проекта

```
frontend/
├── index.html            # Входная точка
├── vite.config.js        # Конфигурация Vite
├── src/
│   ├── main.jsx          # Точка входа React
│   ├── App.jsx           # Главный компонент с навигацией
│   ├── App.css           # Стили
│   ├── screens/          # Экраны приложения (1–6)
│   └── utils/            # Утилиты (прогноз, форматирование, localStorage)
docs/                     # Документация проекта
.github/workflows/        # GitHub Actions (деплой)
```

## Экраны

1. **Точка входа** — приветствие и кнопка «Начать»
2. **3 вопроса** — возраст, доход, цель кредита
3. **Прогноз одобрения** — честная оценка без влияния на КИ
4. **Симулятор** — «Что будет если» с реальными цифрами
5. **Карточка продукта** — рекомендация Альфа-Карты Первой
6. **Подтверждение** — подготовка к заявке
