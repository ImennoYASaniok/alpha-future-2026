# Alpha Future 2026 — «Первый кредит без страха»

Прототип для кейса **«Банковское приложение будущего»** (хакатон Alpha Future 2026).

**Проблема:** Молодые люди 18–25 лет боятся кредитных карт: непонятные условия, страх испортить кредитную историю, переплаты. Банковские приложения перегружены сложными таблицами и договорами.

**Решение:** Интерактивный прототип, который проводит пользователя от первых вопросов до готовности оформить карту за 6 простых шагов. Без мелкого шрифта. Без скрытых комиссий. Только понятные сценарии и «честный прогноз».

**Цель:** Показать, как банковское приложение будущего может обучать, а не запугивать — через прозрачность, геймификацию и персонализацию.

**Ключевая метрика:** пользователь понимает продукт до оформления заявки и принимает осознанное решение.

---

## Стек

- **Frontend**: React 18 + Vite
- **Стили**: Vanilla CSS (custom properties, clamp)
- **Хранение**: localStorage (все данные на клиенте)
- **Роутинг**: кастомная навигация (стек экранов), без react-router
- **Деплой**: GitHub Pages (через GitHub Actions), Vercel

## Быстрый запуск

```bash
# 1. Установить зависимости
cd frontend
npm install

# 2. Запустить dev-сервер
npm run dev
```

Открыть `http://localhost:5173` в браузере. Dev-сервер поддерживает Hot Module Replacement.

## Сборка

```bash
cd frontend
npm run build
```

Готовая сборка в папке `frontend/dist/`. Можно открыть `dist/index.html` локально или запушить для авто-деплоя.

## Деплой

### GitHub Pages

При пуше в ветку `main` GitHub Actions (`.github/workflows/deploy.yml`) автоматически:
1. Устанавливает зависимости (`npm ci`)
2. Собирает проект (`npm run build`)
3. Публикует содержимое `frontend/dist/` на GitHub Pages

Ручной триггер — через вкладку Actions → Deploy → Run workflow.

### Vercel (дублирующий прототип)

Подключён репозиторий к Vercel: пуши в `main` деплоятся на `alpha-future-2026.vercel.app` автоматически. Настройки:
- **Root directory**: `frontend`
- **Framework preset**: Vite
- **Build command**: `npm run build`
- **Output directory**: `dist`

## Экраны приложения

### 1. Приветствие (Screen1)
Центрированный экран с логотипом (девушка с картой) и кратким описанием. Кнопка «Начать» запускает онбординг.

### 2. Анкета — 3 вопроса (Screen2)
Прогресс-бар + 3 последовательных вопроса с выбором варианта:
- **Возраст**: 18–20 / 21–23 / 24–25
- **Доход**: работаю / фриланс / нет
- **Цель**: повседневные покупки / просто попробовать / крупная покупка

Каждый шаг анимирован. Можно вернуться назад.

### 3. Прогноз одобрения (Screen3)
**Ключевой экран продукта.** На основе ответов запускается скоринговая модель:

- Каждый ответ приносит баллы (возраст: 10–30, доход: 5–45, цель: 5–15)
- Максимум 90 баллов → вероятность 15–95%
- Показывается **числовая вероятность** (например, 73%) + категория («средняя»)
- Цвет индикатора: зелёный (высокая) / оранжевый (средняя) / красный (низкая)
- Текстовое пояснение: почему именно такой прогноз
- Список «Что учли в прогнозе»
- При низкой вероятности — подсказки «Что можно сделать» и кнопка «Попробовать позже»

Скоринг описан подробно в [docs/approval_forecast.md](docs/approval_forecast.md).

### 4. Симулятор «Что будет если» (Screen4)
Интерактивный блок — пользователь меняет параметры и видит, как меняется ежемесячный платёж:
- **Лимит**: слайдер 5 000 – 100 000 ₽
- **Льготный период**: тумблер (да / нет)
- **Минимальный платёж**: тумблер (да / нет)

Результаты обновляются в реальном времени: сумма процентов, ежемесячный платёж, флаг «успеваете в ЛП».

### 5. Карточка продукта (Screen5)
Рекомендация «Альфа-Карта Первая»:
- Лимит: до `getLimitCap()` (зависит от возраста/дохода)
- Кэшбэк до 1%
- Льготный период 60 дней
- Процентная ставка 23%, обслуживание 0 ₽ в первый год
- Кнопка «Посмотреть другие варианты» — дополнительные карты

### 6. Подтверждение (Screen6)
Финальный экран — «Подготовка к заявке». Успокаивающий текст, что скоринг — это игра, а не реальная заявка.

## Ключевые технические решения

### Скоринговая модель (`forecast.js`)

Вместо трёх if-ов реализована балльная система:

| Фактор | Вариант | Баллы |
|--------|---------|-------|
| **Возраст** | 18–20 | 10 |
| | 21–23 | 20 |
| | 24–25 | 30 |
| **Доход** | Работаю | 45 |
| | Фриланс | 25 |
| | Нет | 5 |
| **Цель** | Повседневные | 15 |
| | Попробовать | 10 |
| | Крупная | 5 |

Формула вероятности: `15 + (score / 90) * 80` → диапазон 15–95% (банки не дают 0% и 100%).

Рекомендованный лимит: 10 000 / 20 000 / 50 000 ₽ в зависимости от скора.

Подробнее — в [docs/approval_forecast.md](docs/approval_forecast.md).

### Навигация

Кастомный стек экранов в `App.jsx`:
- Хранится в стейте `screenIndex` + `history[]`
- Анимация fadeIn через CSS-класс
- Поддержка «Назад» без браузерного history

### Адаптив

- `clamp()` для шрифтов и отступов
- `min-height: 100dvh` для современных браузеров
- `max-width: 420px` — имитация мобильного экрана
- Всегда центрировано, не зависит от размера окна

## Разработка

### Добавление нового экрана

1. Создать `src/screens/ScreenN.jsx`
2. Импортировать в `App.jsx`
3. Добавить в массив `SCREENS`
4. Прописать стили в `App.css`

### Добавление новой утилиты

1. Создать файл в `src/utils/`
2. Экспортировать функции
3. Импортировать в нужный экран
